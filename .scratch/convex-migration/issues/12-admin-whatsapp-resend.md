# 12: Admin WhatsApp resend

**What to build:** An admin sends a WhatsApp message to a customer from the admin UI, so a
lost voucher can be resent without leaving the dashboard.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] An admin can send a message to a customer and sees whether it was delivered or failed.
- [ ] A staff-role or public caller cannot send anything.
- [ ] The message content is derived server-side from the voucher rather than accepted
      wholesale from the client.
