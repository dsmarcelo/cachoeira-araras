# 01: Marcar a compra como serviço no Mercado Pago

**What to build:** Fazer o checkout identificar a compra do Voucher como um serviço, para que o Mercado Pago não apresente ao cliente garantias e mensagens próprias da entrega de produtos físicos.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Toda preferência criada para uma compra normal ou de teste classifica seu item como serviço.
- [ ] O restante dos dados da preferência, incluindo preço, descrição e retorno, permanece inalterado.
- [ ] Um teste focado comprova a categoria enviada ao Mercado Pago.
