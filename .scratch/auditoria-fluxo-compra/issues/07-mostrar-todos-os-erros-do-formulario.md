# 07: Mostrar todos os erros do formulário de uma vez

**What to build:** Mostrar ao cliente todos os problemas conhecidos do formulário na primeira tentativa de envio, para que nome, telefone, Visit Date e quantidades possam ser corrigidos em uma única passada.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] O erro de telefone aparece mesmo quando outros campos básicos também estão inválidos.
- [ ] Uma submissão vazia mostra simultaneamente os erros de todos os campos obrigatórios aplicáveis.
- [ ] A regra de telefone continua aceitando e rejeitando os mesmos formatos definidos para a compra.
- [ ] Testes focados cobrem múltiplos erros simultâneos, sem testar detalhes internos da biblioteca de validação.
